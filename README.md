# 🐍 Python Discount Calculator (GUI Application)

A beginner-friendly desktop GUI application built with **Python (Tkinter)** that calculates total prices after applying discounts and quantities. Created as part of the **Advanced Teacher Preliminary Evaluation at Koding Next**.

---

## 📌 Features & Pedagogical Highlights
- **Graphical User Interface (GUI):** Built with Python's built-in `tkinter` library to simulate a real point-of-sale calculator.
- **Robust Error Handling:** Uses `try-except` blocks to prevent application crashes when users input invalid characters or leave fields blank.
- **Extensive Study Guide Comments:** The source code is heavily commented in English with insightful explanations and copy-paste reusable patterns, serving as an effective self-study guide for students.

## 🚀 Prerequisites & How to Run

1. Make sure Python is installed on your computer.
2. Open your terminal or command prompt.
3. Run the application script:
   ```bash
   python discount_calculator.py
   ```

---

## 🧠 Code Architecture & Logic
- **Data Types (`float` vs `int`):** Utilizes `float` for prices to accommodate decimals and `int` for quantities to ensure whole-number item counts.
- **Modular Layout:** Uses Tkinter `Frame` and `pack()` layout manager to organize input fields cleanly.
